# How to Run This Project

### Step 1: Create a Folder
Create one new folder on your computer. Call it `fashion-deck`.

### Step 2: Save the Files
Save all three files (`index.html`, `style.css`, `script.js`) inside this **one folder**.

*   **Check the names carefully.** The stylesheet must be named `style.css`, not `style.css.txt`.
*   The script must be named `script.js`.
*   The main file must be `index.html`.

Your folder should look like this:
```
- fashion-deck
  |- index.html
  |- style.css
  |- script.js
```

### Step 3: Open in Browser
Double-click the `index.html` file. It will open in your web browser and should now look correct.
